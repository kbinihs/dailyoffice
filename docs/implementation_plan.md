## 5.5단계 — 디자인 적용 (6단계 전, [Bin] 요청 2026-11-02)

Material 3 뼈대에 교회 보라·한글 글꼴을 입힌 디자인 시스템 「매일, 함께」(design.md 8절)를 앱에 옮김. `@material/web` 2.5.0(정식 컴포넌트만, labs 없음).

- ✅ 첫 화면 모션(`src/splash.ts`): 십자가 막대가 세로·가로로 그려지고 빛살, "매일, 함께". 기록을 불러오는 동안 앞을 가리고 다 그린 뒤 위로 걷힘. 누르면 바로, 동작 줄이기 설정이면 짧게.
- ✅ 하단 탭 홈·기도(🙏)·말씀, 설정은 상단 바 단추(뒤로 가면 설정을 열기 전 화면). 상단 바는 스크롤하면 한 단계 올라옴.
- ✅ 홈(`src/screens/home.ts`): 날짜·절기, 매튜 헨리 인용(요일, `henry-quotes.json` `slots.home`) + 개역한글 구절, 오늘의 기도 타일 🌅☀️🌙(누르면 `#/pray/<시간대>`), 오늘의 말씀(범위·일차·진도, "읽기").
- ✅ 기도: M3 구분 단추, 인도자 assist chip + md-dialog, 마침은 extended FAB. 말씀: md-tabs, 밀린 날·다음 날은 md-list, 달 넘김은 아이콘 단추. 설정: md-slider, 단추, 지우기 확인은 md-dialog.
- 떠 있는 막대·FAB는 z-index 1(md-dialog 가림막이 덮도록). 화면 밝기 "기기 설정대로"는 휴대폰 폭에서 두 줄이 되어 "자동"으로.
- 확인: 375px 휴대폰 폭, 밝게·어둡게, 첫 화면 → 홈 → 기도(함께, 인도자 더하기·빼기, 마침) → 홈 타일 마침 표시 → 말씀(오늘·진도·날짜 열기·뒤로) → 설정(지우기 확인 창, 뒤로). 콘솔 오류 없음. 테스트 93개. 번들 379KB(gzip 91KB).
- 6단계로: 글꼴·아이콘(Google Fonts)도 서비스 워커로 캐시해야 오프라인에서 모양이 유지됨. → 6단계에서 함.

## 세션 수 합계

코드 7세션 + 콘텐츠 3세션 + 착수 전 확보(별도). 0·1단계가 끝나 있으면 2~6단계는 연속 3일 안에 가능하다. 병목은 코드가 아니라 **1.2~1.6 번역 검수와 0.4 데이터 이용 조건 확인**이다.

## 의존 관계

```
0.1 ──┐
0.5 ──┼─→ 1.1 → 1.2 → 1.3 → 1.6 ─┐
0.4 ──┼─→ 2.6 ───────────────────┼─→ 3 → 4 → 5 → 6 → 7
0.3 ──┘                          │
0.6 ──→ 2.1 ─────────────────────┘
```

2단계는 0단계 데이터 없이도 샘플로 시작할 수 있다. 단 3단계는 1.2가 끝나야 실물 검증이 된다.
