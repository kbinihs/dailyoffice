# 저작권 정리 — 매일, 함께

> 관련 문서: [[prd]] · [[design]] · [[implementation_plan]]
> 법률 판단이 아니라 공개된 고지를 읽고 정리한 것이다. 배포 전에 아래 "남은 확인"을 끝낸다.

## 원칙

1. **번역 원문은 BCP 2019(ACNA)다.** 일일기도 요소와 절기 기도 모두 2019년판 본문을 옮긴다.
2. 2019년판은 "All rights reserved"다. 교회가 예배 주보·자료에 쓰는 것은 권장하지만, 번역과 앱 사용은 고지에 언급이 없다. **출판사(Anglican House Publishers) 허가는 빈이 직접 확인한다.**
3. 성경 구절은 개역한글(저작재산권 만료)만 쓰고 출처를 표기한다. 주기도문만 새주기도문이다.

## 성경 본문을 바꿔 쓰는 곳

- **축복(민 6:24-26) 2인칭**: 26절 끝 "할찌니라 하라"(모세에게 주신 지시)만 뺀다. 인용 범위를 줄인 것이고 본문은 그대로다.
- **축복 1인칭 복수, 은혜의 기원(고후 13:13)의 "우리"**: 성경 본문을 바꾸는 것이므로 성경 인용으로 표시하지 않고 "민수기 6:24-26을 따라", "고린도후서 13:13을 따라"로 표기한다. 동일성유지권 문제를 피하는 방법이다.
- 장절 번호는 한국어 성경 기준으로 적는다. BCP 2019 시편(New Coverdale)과 번호가 다른 곳은 `bcp_ref`에 남긴다(예: 시 16:8-9 → 16:7-8, 고후 13:14 → 13:13).

## 데이터 원천

- 개역한글 본문 데이터: GitHub `bluesaurel/Korean-Bible-1961-KRV`. 본문은 퍼블릭 도메인이지만 저장소에 라이선스 표기가 없다. 저장소에 이용 문의를 남기거나, 장·절 구조가 같은 다른 원천과 대조해 직접 변환한다.
- BCP 2019 전체 PDF: ACNA 공식 사이트에서 공개(https://bcp2019.anglicanchurch.net/). 폴더의 `BCP-2019-MASTER-5th-PRINTING-05022022-3.pdf`(5쇄)에서 절기 기도를 옮겼다.
