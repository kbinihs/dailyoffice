# 번역 검토 — 매일, 함께 (2026-11-02)

대상: `content/elements.json`의 BCP 2019 기도문(고백·용서·감사·마침·요일 기도 14편·낮 기도·선교 3편·절기 26편)과 지시문, `content/henry-quotes.json` `slots.home.quotes` 37편.
기준: `content/translation-notes.md`, `CLAUDE.md` 절대 규칙, `docs/design.md` 2·3·7절. 이미 검토한 것(`docs/review-*.md`, `implementation_plan.md` 변경 기록)은 되풀이하지 않았다.
표기: CURRENT/PROPOSED 안의 `\n`은 JSON 그대로의 줄바꿈(호흡) 표시. PROPOSED는 그대로 붙여 넣을 수 있는 전체 본문이다.
우선순위: **A** 분명히 낫다(적용 권고) / **B** 선택(소유자 취향).

## 1. 총평

- 강점: 합쇼체와 "~하소서"가 한결같고, 긴 원문을 2~3문장으로 끊어 혼자서도 여럿이서도 소리 내 읽기 좋다. 호칭(아버지의/주님의)과 마침 문구 규칙이 거의 빈틈없이 지켜졌다. 헨리 인용은 붙여 둔 개역한글 구절의 낱말(바라다, 엎드러지다, 찬송, 쉼표)을 받아 번역이 구절과 맞물린다. 대체로 이미 좋은 번역이고, 아래 제안은 다듬기다.
- 되풀이되는 약점 다섯 가지: (1) 영어 연어를 따라간 자리 — 팔을 "펼치다", 잠을 "깨뜨리다", "눈이 우리 위에", 위험에 "이르다". (2) 다 함께 읽는 기도(고백·감사)에 35자 넘는 줄이 남아 한 호흡에 벅차다. (3) 하나님·그리스도가 주어인 자리에 "가"(아버지가, 그리스도가)가 두 곳. (4) 원문의 청원이나 태도가 조용히 빠진 곳(선교 3 "사랑의 영을 보내셔서", 감사 "참으로 감사하는 마음으로"). (5) 집안 규칙과 어긋난 낱말 — 성금요일 "가족"(규칙 4), 수요일 밤 "우리 주"(원칙 3절은 "우리 구주"), 사순 4주 "빵" vs 목요일 밤 "떡".

제안 수: A 14 (기도문 5, 인용 9) / B 24 (기도문 20, 인용 4).

## 3. `translation-notes.md`에 더할 것

1. **규칙 4의 범위(8절에 덧붙임)**: "가족·부모·자녀…" 금지는 지시문·안내문·화면 문구에 적용한다. 기도문 안의 성경적 용례("하나님의 자녀", 요 1:12)는 허용하되, "family"(교회를 뜻함)는 "백성"으로 옮긴다. — 이렇게 적어 두지 않으면 성탄일 "자녀"와 성금요일 "가족"이 세션마다 다시 문제가 된다.
2. **낱말 고정(6절에 더함)**: bread → 떡(개역한글·목요일 밤 "떡을 떼실 때"와 맞춤; "빵"으로 정하면 둘 다 바꿈) / the just → 의인 / heaven(헨리 인용) → 천국·하늘나라, "하늘"만 쓰지 않음 / care(하나님이) → 돌보시다.
3. **주격 조사(1절에 더함)**: 하나님·아버지·주님·예수 그리스도가 주어이면 "께서" 또는 주제의 "는". "가/이"는 쓰지 않는다.
4. **연어 점검(1절 "직역보다 뜻"에 예로 더함)**: 팔을 벌리다(펼치다 ×), 잠을 깨우다(깨뜨리다 ×), 위험을 만나다·당하다(위험에 이르다 ×), 눈길이 머물다(눈이 위에 있다 ×).
5. **줄 길이**: 다 함께 읽는 요소(죄의 고백·감사의 기도·주기도문)는 한 줄 30자를 넘기지 않는다(design.md 7절 25자 안팎을 수치로). 인도자 혼자 읽는 기도는 35자까지 봐준다.
6. **마침의 예외(3절에 한 줄)**: 원문이 "through…"도 삼위 송영도 없이 청원으로 끝나면(밤 일요일) "…하소서. 아멘."으로 끝낸다. 빠뜨린 것이 아니다.
