# PRD — 매일, 함께

> 관련 문서: [[design]] · [[implementation_plan]]
> 앱 이름(가칭): 「매일, 함께」. 아래에서는 「앱」으로 부른다.

## 1. 한 줄 정의

교인 누구나(혼자든, 어떤 형태의 '함께'든) 성공회 기도서의 일일 기도 구조로 아침·낮·밤에 기도하고, 교회 통독표의 같은 페이스로 성경을 읽어 가도록 돕는, 서버 없는 정적 웹앱.

## 2. 배경과 문제

- 교회가 통독표를 주지만 각 가정이 그것을 "함께" 읽는 틀은 없다. 통독은 개인 과제로 남고, 가정 예배는 형식이 없어 시작하기 어렵다.
- 성공회 기도서(BCP)의 Daily Office와 Family Prayer는 수백 년 검증된 가정·개인 기도 구조를 갖고 있으나 한글로, 그리고 모바일에서 바로 쓸 수 있는 형태가 없다.
- 참고 서비스 dailyoffice2019.com은 교회력 계산을 중심으로 한 대규모 풀스택이라 그대로 가져올 수 없다. 구조 발상만 빌린다.

## 3. 목표

1. 하루 세 번(아침·낮·밤) 기도할 수 있는 한글 기도 순서를 제공한다. 아침·낮은 짧게, 밤은 '함께'를 전제로 한 본 예식.
2. 교회 통독표를 일차별로(일요일 제외 주 6일) 보여 주고 각자 읽고 체크하게 한다. 교회 전체가 같은 본문을 읽고 있다는 감각을 유지한다.
3. 혼자 기도하는 사람과, 부부·부모자녀·조부모손주·룸메이트·소그룹 등 모든 형태의 '함께'가 같은 화면으로 걸림 없이 쓴다.
4. 기도와 읽기의 기록은 **각자 기기에만** 남긴다.

## 4. 비목표 (명시적 제외)

- 교회 단위 집계·순위·통계. 기록을 서버로 보내지 않는다.
- 로그인, 계정, 가구 구성 등록.
- 교회력 전체(주현절, 성령강림 후 절기, 성인 축일). 절기는 대림·성탄·사순·고난주간·부활만 다룬다.
- 스토어 네이티브 앱. PWA(홈 화면 추가)로 끝낸다.
- 음성 낭독, 알림 푸시(1차 범위 밖. 필요하면 2차).
- 성경 본문 주석·해설.

## 5. 사용자

| 사용자 | 상황 | 핵심 요구 |
|---|---|---|
| 혼자 기도하는 교인 | 출근길·점심·취침 전, 1~7분 | 열면 바로 오늘 기도가 뜨고 역할 표시 없이 한 흐름으로 읽힌다 |
| 함께 기도하는 둘 이상 | 저녁 식탁 또는 잠자리 전, 7~10분 | 누가 어느 줄을 읽는지 한눈에 보이고, 아이도 인도할 수 있다 |
| 통독 참여 교인 | 하루 중 아무 때 | 오늘 범위, 밀린 범위, 본문, 체크 |
| 운영자(교역자·담당 교인) | 연초, 통독표 변경 시 | CSV 한 장 교체로 통독표를 바꾼다 |

## 6. 핵심 시나리오

1. **밤, 둘 이상.** 앱을 열면 시간대에 맞춰 '밤' 예식이 뜬다. '함께'로 전환하고 오늘 인도자를 고른다. 인도자 줄은 강조, '다 함께' 줄은 전체 강조. 시편을 교독하고, 마지막에 서로를 향해 축복문을 읽는다. 끝내면 오늘 밤 기도에 체크된다.
2. **아침, 혼자.** 열면 '아침'이 뜬다. 혼자 모드가 기본이라 역할 표시가 없다. 2~3분 분량. 끝에 "오늘 통독: 창 4-6장" 링크가 있어 함께 읽기로 넘어갈 수 있다.
3. **함께 읽기.** 오늘 범위와 본문(개역한글). 읽으면 체크. 사흘 밀렸으면 밀린 날짜가 접혀 있고 펼쳐서 따라잡는다. 상단 한 줄: "오늘 ○○서 ○장을 읽습니다."
4. **운영자.** 새해 통독표를 CSV로 바꿔 저장소에 올리면 다음 배포에 반영된다.

## 7. 기능 요구

### 필수 (1차 배포 조건)
- 세 시간대 기도 순서: 아침·낮(짧은 형식), 밤(밤기도 Compline: 고백, 밤기도 시편·말씀, 주님 손에 맡김, 밤의 기도, 시므온의 노래, 축복). 구성은 [[design]] 3절. 2026-11-03 밤 예식을 저녁기도에서 밤기도로 바꿈.
- 혼자 / 함께 모드 전환. 함께 모드에서 인도자 배정(이름 입력, 저장은 기기 로컬).
- 역할 표시: 인도자 / 나머지 / 다 함께.
- 날짜 기반 본문 결정: 요일별 기도·여는 말씀, 182일 시편 주기(1년 2독, 아침), 낮의 기도·밤기도의 시편·말씀·기도는 날마다 차례로. 기기가 달라도 같은 날 같은 본문.
- 함께 읽기: 교회 통독표(CSV) 기반 일차별 범위(일요일 제외 주 6일), 개역한글 본문 표시, 일차별 체크, 밀린 날 따라잡기.
- 기록: 기도(시간대별)·읽기 체크를 기기 로컬에 저장. JSON 내보내기·가져오기(기기 바꿀 때).
- 오프라인 동작(PWA, 서비스 워커). 설치 안내.
- 글자 크기 조절, 다크 모드.
- 카카오톡 공유 시 미리보기(OG 태그).
- 절기: 대림·성탄·사순·고난주간·부활(승천·성령강림 포함) 기간에 절기 여는 말씀과 그 주의 절기 기도(26편)를 아침·밤 예식에 더한다. 부활절기에는 마침 교송에 알렐루야.

### 권장 (1차에 넣되 미뤄도 됨)
- 기도 중 화면 꺼짐 방지(Wake Lock API, 지원 브라우저 한정).
- 시간대 자동 선택(현재 시각 기준) + 수동 전환.
- 연속 기록(스트릭) 표시 — 단, 끊겼을 때 질책하는 문구 없음.

### 보류 (2차 이후)
- 주현절·성인 축일 기도.
- 아침·낮 알림(웹 푸시).
- 통독 범위 외 자유 읽기(성경 전체 탐색).
- 다교회 지원(교회별 설정 파일 분리).

## 8. 비기능 요구

- **개인정보**: 수집 0. 이름은 기기 로컬에만. 분석 도구 없음. 개인정보처리방침이 필요 없는 구조를 유지한다.
- **저작권**: 성경 본문은 개역한글(1961, 저작재산권 만료)만 내장하고 출처를 표기한다. 주기도문은 새주기도문(비영리 사용 가능 확인). 기도문은 BCP 2019 원문을 번역한다(출판사 허가는 빈이 확인). 『성공회기도서』 본문은 허락 없이 쓰지 않는다. 자세한 내용은 [[rights]].
- **성능**: 첫 로드 1MB 이하(성경 본문은 책 단위 분할 로드). 오프라인 2초 안에 열림.
- **접근성**: 본문 글자 최소 18px 기본, 명암비 WCAG AA, 화면 낭독기에서 역할 라벨이 읽힘.
- **유지보수**: 비개발자(운영자)가 CSV와 JSON만 고쳐 콘텐츠를 바꿀 수 있어야 한다. 빌드 의존성 최소.

## 9. 성공 기준

집계를 하지 않으므로 숫자는 파일럿 설문으로만 얻는다.
- 파일럿(5~10가구, 2주) 뒤: "이번 주 세 번 이상 썼다" 70% 이상, "다음 달도 쓰겠다" 70% 이상.
- 혼자 쓰는 참여자가 "함께 모드의 축소판처럼 느껴진다"고 답하지 않는다(정성 확인).
- 운영자가 도움 없이 통독표를 교체한다(1회 시연).

## 10. 리스크

| 리스크 | 영향 | 대응 |
|---|---|---|
| BCP 2019 사용 범위가 좁음(확인: All rights reserved, 예배 자료 사용만 명시 허용) | 앱 배포가 막힘 | 출판사에 허가 확인(빈). 대비책: 대부분의 기도는 1662·1928·1979년판에 같은 기도(퍼블릭 도메인)가 있음 |
| 개역한글 문체가 아이들에게 낯섦 | 시편 교독이 어색 | 받아들인다. 역본 혼용은 하지 않는다(일관성 우선) |
| 기기 로컬 기록은 기기 바꾸면 사라짐 | 사용자 불만 | JSON 내보내기·가져오기. 설정 화면에 명시 |
| 교회 통독표가 중간에 바뀜 | 데이터 재작업 | CSV 교체로 끝나게 설계. 읽기 체크는 연도·일차 기준이라 유지 |
| 참여 저조 | 앱이 아니라 공동체 문제 | 앱으로 풀지 않는다. 주일 나눔 시간 설계는 교회 몫으로 분리 |

## 11. 결정 사항 (기본값으로 정함 — 검토 후 변경 가능)

1. **가칭**: 「매일, 함께」. 지금은 이 폴더(`dev/dailyoffice`)에서 작업하고, 코드가 진행되면 GitHub 저장소로 옮긴다.
2. **번역**: 원문은 BCP 2019. 어투는 청파교회 주보 공동기도의 결을 따라 합쇼체("합니다/해 주십시오")로 쓰고, 삼위 송영은 "예수님의 이름으로 기도드립니다" 한 문장으로 갈음한다. 원칙은 `content/translation-notes.md`.
3. **지시문 어휘**: 부모·자녀·가족이라는 말을 쓰지 않는다. 인도자·나머지·서로·다 함께.
4. **밤 예식의 요일 기도**: BCP 2019 Evening Prayer의 요일별 기도 7편. 아침은 Morning Prayer의 7편(월요일 '새 생명의 기도' 포함).
5. **시편**: 1년 2독(182일 주기). 아침 예식에서 하루 한 편 또는 긴 시편의 한 단락을 교독한다(2026-11-03 밤에서 옮김). 밤기도는 밤기도 시편 네 편(4·31:1-6·91·134)이 날마다 돈다. 교회 통독표의 시편 범위와는 연결하지 않는다.
6. **교회명**: 화면에 넣지 않는다(2026-11-02 Bin 결정). 설정 파일에서도 뺐다.
7. **기록 저장**: IndexedDB(용량·구조 여유), localStorage는 설정만.
8. **통독표 날짜 대응**: 일요일을 뺀 주 6일. 시작일은 매년 1월 1일(`plan-config.json`의 `startDate`가 비어 있으면 자동). 일차 기반이라 같은 통독표를 해마다 다시 쓸 수 있다.
9. **주기도문**: 새주기도문.
10. **절기**: 대림·성탄·사순·고난주간·부활. 절기 기도는 주마다 바뀌고(고난주간 목·금·토는 날마다), 요일 기도 앞에 더한다.

## 12. 열린 질문

- 출판사 허가(빈 확인 중), 개역한글 데이터 이용 조건 — [[rights]] "남은 확인".
- 선교 기도 3편 순환 vs 1편 고정 — 1차는 순환으로 가되 파일럿 피드백으로 재결정.
